# Nailed by Ellie — Luxury Nail Studio Website

## Project Overview
This is a fully responsive, multi-page website built for **Nailed by Ellie**, a fictional luxury nail studio. The website is designed to provide a premium, immersive experience for clients, allowing them to explore services, view a portfolio of nail art, read testimonials, and book appointments. 

The primary goal was to create a visually stunning brand identity using full-page background images, glassmorphism UI elements, and seamless interactive features.

**Live Website:** `https://[YOUR-GITHUB-USERNAME].github.io/[YOUR-REPO-NAME]/`

## Technologies Used
*   **HTML5:** Semantic structure across four distinct pages.
*   **CSS3:** Custom properties (variables), Flexbox, CSS Grid, and advanced styling (backdrop-filter for glassmorphism).
*   **JavaScript (Vanilla):** For interactive UI elements (mobile navigation, form handling).
*   **Font Awesome:** For scalable vector icons.
*   **Google Fonts:** Playfair Display (headings) and Poppins (body text).

## Website Pages
1.  **Home (`index.html`):** Features a full-page immersive background, a glassmorphism overlay introducing the brand, client testimonials, and brand promises.
2.  **Services (`services.html`):** A clean, responsive CSS Grid displaying the full menu of nail services (Manicure, Pedicure, Gel, Acrylics, etc.) with pricing.
3.  **Gallery (`gallery.html`):** A responsive image grid showcasing recent nail art, alongside a dedicated client review section and a form to submit new reviews.
4.  **Book Now (`contact.html`):** A clean, user-friendly booking form that captures client details and service preferences.

## Key Interactive Features (JavaScript)
*   **Mobile Navigation:** A fully functional hamburger menu that toggles the navigation drawer on smaller screens.
*   **Smooth Form Handling:** Both the Booking form and the Review form prevent page reloads. Instead, they smoothly hide the form and display a custom, beautifully styled "Thank You" success message.
*   **Accessibility:** `aria-expanded` attributes are updated dynamically on the mobile menu toggle for screen readers.

## Responsive Design
The website is built mobile-first and is fully responsive across all devices:
*   **Mobile (375px):** The menu collapses into a hamburger toggle, grids stack into a single column, and text sizes scale down for readability.
*   **Tablet (768px):** The navigation bar expands horizontally, and service cards arrange into a 2-column grid.
*   **Desktop (1260px+):** The full layout expands, with service grids filling 3 to 4 columns and backgrounds remaining fixed for an immersive parallax effect.

## How to Run Locally
1. Clone the repository or download the ZIP file.
2. Ensure all images (`hero-bg.jpg`, `logo.jpeg`, `gallery1.jpg`, etc.) are in the same folder as the HTML files.
3. Open `index.html` in any modern web browser (Chrome, Safari, Firefox).
